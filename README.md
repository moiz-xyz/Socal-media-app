# 🚀 Real-Time Social Media App

A feature-rich social media application with **real-time posting, user authentication, and live data fetching**, powered by **Supabase** for the backend.

## 🔹 Features
✅ **Real-Time Posting** – Instantly update posts without refreshing  
✅ **User Authentication** – Secure login & signup with Supabase Auth  
✅ **Live Data Fetching** – Seamless and dynamic user experience  
✅ **Supabase Backend** – Fast, scalable database & storage  
✅ **Responsive UI** – Optimized for all devices  

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Supabase (PostgreSQL, Authentication, Realtime Database)  
- **Other:** REST APIs, Responsive Design  

## 🚀 Getting Started

### Clone the repository:
```bash
git clone https://github.com/your-username/social-media-app.git
```

### Install dependencies:
```bash
npm install  
```

### Set up your Supabase API keys:
Create a `.env` file and add:
```
SUPABASE_URL=your-supabase-url
SUPABASE_KEY=your-supabase-anon-key
```

### Run the app:
```bash
npm start  
```
